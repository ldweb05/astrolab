# Affinamento UX Astrolab comparato con MyAstral.org

## Finalità

Questo percorso documenta l'affinamento dell'esperienza operativa di Astrolab tramite un confronto metodologico con MyAstral.org di Ciro Discepolo.

MyAstral.org viene utilizzato esclusivamente per comprendere:

- il modello mentale dell'astrologo;
- l'ordine naturale delle attività;
- la reperibilità delle funzioni;
- la continuità dei flussi;
- la chiarezza delle informazioni;
- il numero di passaggi richiesti.

## Principio fondamentale

MyAstral.org non è un modello da copiare.

Astrolab deve conservare:

- identità;
- UI;
- architettura;
- funzionalità;
- superiorità tecnica.

L'obiettivo è migliorare il workflow astrologico di Astrolab.

## Separazione dal piano tecnico

Questa cartella non costituisce una roadmap tecnica.

Le osservazioni UX seguono obbligatoriamente questo percorso:

1. osservazione;
2. raccolta delle evidenze;
3. confronto;
4. proposta;
5. valutazione;
6. decisione documentata;
7. eventuale trasferimento futuro nella roadmap tecnica.

Nessuna osservazione autorizza direttamente modifiche al codice.
