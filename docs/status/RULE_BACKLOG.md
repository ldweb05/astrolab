# DIRETTIVA OPERATIVA PERMANENTE

L'architettura attuale di Astro-Val è congelata.

Non sono consentiti:

- nuove versioni architetturali;
- nuovi layer;
- refactoring generali;
- riprogettazioni speculative;
- strumenti non necessari al completamento;
- variazioni dei contratti stabili, salvo bug documentati.

L'obiettivo obbligatorio è portare avanti e completare il progetto
utilizzando esclusivamente la pipeline e i contratti attuali.

Le attività ammesse sono:

- aggiungere conoscenza astrologica;
- implementare Rule e Composite Rule;
- completare Theme Engine, Narrative Engine e Annual Report;
- aggiungere test;
- correggere bug concreti;
- eseguire la Full Regression;
- aggiornare la documentazione;
- effettuare commit Git.

Ogni singolo passaggio eseguito deve essere registrato cronologicamente
in `docs/HANDOVER_OPERATIVO.md`.

Ogni registrazione deve indicare:

- data;
- obiettivo;
- file creati o modificati;
- risultato;
- test eseguiti;
- commit Git;
- prossimo passo operativo.

Un nuovo sviluppatore non deve reinterpretare o riprogettare Astro-Val.

Deve leggere `docs/HANDOVER_OPERATIVO.md` e continuare esattamente
dal prossimo passo indicato.
